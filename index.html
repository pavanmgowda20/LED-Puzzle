TRANSMISSION: INSTRUCTIONS

THE MISSION

Establish a closed electrical circuit by SLIDING wire tiles into empty sockets across the matrix. Tile wiring orientations are fixed and cannot be rotated. Power must flow continuously from (+), through the light bulb, and back to (-).

THE CONTROLS

  • Slide Tile: Click or tap any tile adjacent to an empty socket to slide it in.
  • Push Lines: Clicking a tile in the same row/column as an empty socket pushes all tiles in that line toward the socket!
  • Swipe & Drag: Drag/swipe tiles directly toward empty spaces on touch or mouse.
  • Keyboard Controls: Use Arrow Keys or WASD to slide tiles into the empty space.
  • Locked Obstacles: Identified by orange metal corner brackets. Locked tiles cannot be slid and must be routed around.
  • Instant Timer Save: The exact millisecond your circuit connects and lights the bulb, your completion time is automatically recorded and saved to the Relayathon Log!

TILE CLASSIFICATIONS

Straight: Direct path between opposite sides.
Corner: 90-degree redirection path.
Tee Junction: 3-way distribution junction.
Cross Junction: Independent 4-way crossing paths.

Google Sheets Live Webhook (Apps Script)

Payload delivers each round's split times and cryptographic SHA-256 hash. The script creates separate sheets per round automatically!

📋 Click to view one-click Google Apps Script code for your Google Sheet 
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheetName = "Round " + (data.roundNumber || 1);
    var sheet = ss.getSheetByName(sheetName);
    if (!sheet) {
      sheet = ss.insertSheet(sheetName);
      sheet.appendRow(["Timestamp", "Type", "Participant", "Stage", "Stage Seconds", "Round Seconds", "Moves", "Verification Hash"]);
      sheet.getRange(1, 1, 1, 8).setFontWeight("bold").setBackground("#1a1a2e").setFontColor("#00f2fe");
    }
    sheet.appendRow([
      new Date(),
      data.type || "stage_cleared",
      data.participant || "Runner",
      data.stageId || 1,
      data.stageSeconds || 0,
      data.roundSeconds || 0,
      data.moves || 0,
      data.verificationHash || ""
    ]);
    return ContentService.createTextOutput(JSON.stringify({status: "ok"})).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", error: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
